## 学习背景

在Geek考核阶段一中学习了什么是GitHub，GitHub使用基本流程与如何使用markdown语言。阶段二要求使用git bash完成推送提交到GitHub远程仓库里与如何提交pr,从了解到实践，学习的难度增大.

### 学习Git基本流程，使用GitBash完成基本流程

Git的基本流程就是 clone add commit push 我用我的主页md文件进行试验，克隆我的个人库到本地进行修改之后commit，再push上传，打开GitHub发现真的进行了修改，感觉不可思议，几个口令就进行了修改，实践之后也是了解Git的核心概念


### 使用GitBash推送Hello.md文档到远程仓库

想要把本地文件推送到远程仓库推送到远程仓库，首先要创建一个本地仓库，打开gitbash输入gint init就很简单的创建了仓库，但是要让里面有点东西可不是直接把文件拖进去，需要输入git add hello.md让文件进去暂存区，还要输入git status去检查状态才能进行下一步，之后就是commit让文件进入本地仓库。之后要检查是否绑定远程仓库，进行绑定，最后把Hello.md通过push推送到远程仓库。一套流程清晰严谨又有条理，打开GitHub会看到推送来的文档。

### 实践发起pr

我虽然学习了GitHub上不同词汇的意思，但是要我上传我还是会不知所措。最开始点击fork创建了副本，之后create new file直接创在了stage目录下通过加斜杠改成git-idea/自己的.md才改回来，果然还是要自己动手，最后我也是成发起了自己的第一次pr,过程很艰难，完成后也还有一丝成就感。
