## 学习内容
### Markdown
- 初步了解什么是Markdown（便捷符号标记语言）以及相关语法（一级标题、二级标题、字体加粗、斜体、删除线等等）
- 感悟：对于比较简洁的文本内容，用Markdown就可以非常便捷的完成文本编写，不用反复改动或者自己调节格式就可以渲染出工整的格式
### Github
- 基本掌握仓库创建方法以及文件创建方法
- 个人主页的美化，仓库内容的丰富和分类索引
- 分支以及合并文件
- 感悟：刚开始觉得特别陌生，上手完全磕磕绊绊，但是阶段一结束后对GitHub就比较熟悉了，第二阶段上手时间就短了很多，而且真的弄出点看得到的进步出来非常有成就感，good
### Git以及GitBash
- 掌握了内涵和一定的使用方法，以及关联传送文件的方法
- 感悟：非常神奇啊，刚开始琢磨半天没有进展，然后成功的时候就觉得非常神奇，而且还能跨软件传送，就在那个看起来非常单调的黑色界面
